# Carousel-Images

Simple image carousel in vanilla HTML, CSS, and JavaScript — early front-end learning exercise.

## The problem

You are learning DOM manipulation and CSS transitions. You need a small project that actually moves images, not another todo list tutorial.

## What it does

A horizontal image carousel with next/prev controls in `index.html`, `style.css`, and `script.js`.

## Install

```bash
git clone https://github.com/irachrist1/Carousel-Images.git && cd Carousel-Images
open index.html
```

## How it works

- **Vanilla JS DOM updates.** Script swaps visible slide — no framework abstraction hiding the mechanics.
- **CSS transitions.** Smooth slide changes via stylesheet — separation of structure, style, behavior.
- **Static assets in `images/`.** Self-contained demo — open and learn.
